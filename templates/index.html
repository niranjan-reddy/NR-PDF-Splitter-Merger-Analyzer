01 / EXTRACT

Split a PDF

One new PDF for each comma-separated page or range.

Pages start at 1. Ranges include both endpoints; overlaps are allowed.

02 / COMBINE

Merge PDFs

Choose how many files to upload, then arrange their order.

Changing the count keeps existing selections where possible. Top row comes first.

03 / CONVERT

Images to PDF

Combine multiple images into one PDF, ordered by filename from A to Z.

Supported formats: BMP, GIF, JPEG, PNG, TIFF, and WebP. Each image becomes one page; transparent areas are filled with white.

04 / CONVERT

Documents to PDF

Convert one Word, Excel, PowerPoint, or other supported document to PDF.

Supports common Microsoft Office and OpenDocument files, plus RTF, CSV, HTML, and text. Requires LibreOffice installed on the server.

05 / INSPECT

Analyze PDFs

View page count, file size, encryption status, document metadata, and each page's dimensions and orientation.

Select multiple PDFs at once. Each file gets a separate report. Encrypted files are identified, but protected details are unavailable. No analysis files are saved.

Splitting and merging require unencrypted PDFs. Keep your original files; editing may invalidate digital signatures.
